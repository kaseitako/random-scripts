# Startup-VirtualDesktop 日本語メッセージ設計

## 目的

`Startup-VirtualDesktop.ps1` を普段 PowerShell を読まない日本語利用者にも理解しやすくする。

- スクリプトが明示的に生成する利用者向けメッセージを日本語にする。
- 処理のまとまりごとに日本語コメントを追加する。
- ログの機械処理互換性は維持する。

## 変更範囲

対象は `powershell/startup-virtual-desktop/Startup-VirtualDesktop.ps1` と、その期待動作を確認するエントリポイントテストに限定する。

### 日本語化するもの

- JSONL ログの `message` にスクリプトが直接設定する文言
- `Write-Warning`、`Write-Output`、`throw` にスクリプトが直接設定する文言
- 実行結果の要約文

### 変更しないもの

- ログレベル `Info`、`Warning`、`Error`
- JSONL ログのキーおよびデータ構造
- 結果ステータス `Moved`、`AlreadyPlaced`、`Skipped`、`Failed`
- 内部モジュールから伝播する例外メッセージ
- コマンド名、パラメーター名、設定ファイル形式

## コメント方針

行ごとの逐語的な説明は避け、次の処理単位の直前に日本語コメントを置く。

1. パス解決と Explorer 待機の補助関数
2. 設定ファイル・ログ出力先の決定
3. JSONL ロガーの準備
4. 二重起動を防ぐ Mutex の取得
5. モジュールと設定ファイルの読み込み
6. VirtualDesktop モジュールなどの動作環境確認
7. `-ValidateOnly` による設定検証
8. 仮想デスクトップとアプリケーションの配置・集計
9. 例外の記録と Mutex の解放

コメントは「何をしているか」と「なぜ必要か」が分かる短い表現にする。

## エラー処理とログ互換性

既存の終了コードと例外処理は変更しない。メッセージ本文のみ日本語にし、ログ解析に使われるレベル名、キー、集計データは維持する。

内部モジュールが生成した例外は翻訳せず、そのまま画面とログの `data.error` に記録する。これにより原因調査に必要な原文を失わない。

## テスト

- `-ValidateOnly` の成功出力が日本語であることをプロセス実行で確認する。
- 設定ファイルがない場合のエラー出力が日本語であることを確認する。
- スクリプトが直接使用していた英語メッセージが残っていないことを確認する。
- PowerShell パーサー検証と既存の全 Pester テストを実行する。
