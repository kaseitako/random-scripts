# Startup-VirtualDesktop Japanese Messages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Startup-VirtualDesktop.ps1` が直接生成するメッセージを日本語化し、処理のまとまりを日本語コメントで読みやすくする。

**Architecture:** エントリポイントの制御構造、終了コード、JSONL の構造は維持し、文字列リテラルと説明コメントだけを変更する。プロセス実行テストで画面出力とログ本文を検証し、機械処理用の英語識別子が変わらないことを既存テストで保証する。

**Tech Stack:** PowerShell 7.5、Pester、JSON Lines

## Global Constraints

- 対象は `powershell/startup-virtual-desktop/Startup-VirtualDesktop.ps1` とエントリポイントテストに限定する。
- ログレベル `Info`、`Warning`、`Error` は変更しない。
- JSONL ログのキー、データ構造、結果ステータスは変更しない。
- 内部モジュールから伝播する例外メッセージは翻訳しない。
- 利用者の `virtual-desktop-setting.json` は変更しない。

---

### Task 1: 日本語メッセージの回帰テスト

**Files:**
- Modify: `powershell/startup-virtual-desktop/tests/StartupVirtualDesktop.Entry.Tests.ps1`
- Test: `powershell/startup-virtual-desktop/tests/StartupVirtualDesktop.Entry.Tests.ps1`

**Interfaces:**
- Consumes: `Startup-VirtualDesktop.ps1 -ValidateOnly` の標準出力、標準エラー、JSONL ログ
- Produces: 日本語の成功・失敗メッセージと主要コメントを要求する回帰テスト

- [ ] **Step 1: 失敗するテストを書く**

成功テストの英語期待値を日本語に変え、ログ本文も確認する。

```powershell
$result.Output | Should Match '設定の検証に成功しました'
$messages = @(Get-Content -LiteralPath $logFiles[0].FullName | ForEach-Object { ($_ | ConvertFrom-Json).message })
$messages | Should Contain '起動環境を検出しました。'
$messages | Should Contain '設定の検証に成功しました。'
```

設定ファイル不在テストに日本語エラーの期待値を加える。

```powershell
$result.Output | Should Match '設定ファイル.*存在しません'
```

直接生成していた旧英語文言と、主要な日本語コメントを静的に確認するテストを加える。

```powershell
It 'uses Japanese for messages generated by the entry script' {
    $content = Get-Content -LiteralPath $scriptPath -Raw
    $content | Should Not Match 'Settings validation succeeded'
    $content | Should Not Match 'Desktop layout completed'
    $content | Should Not Match 'Startup virtual desktop failed'
}

It 'documents major processing blocks in Japanese' {
    $content = Get-Content -LiteralPath $scriptPath -Raw
    $content | Should Match '# 設定ファイルとログ出力先を決定する'
    $content | Should Match '# 二重起動を防止する'
    $content | Should Match '# 仮想デスクトップとアプリケーションを配置する'
    $content | Should Match '# 例外をログへ記録し、終了前にリソースを解放する'
}
```

Expected: 日本語の成功出力またはコメントがまだ存在しない理由で `Failed` が 1 件以上になる。

### Task 2: メッセージ日本語化とコメント追加

**Files:**
- Modify: `powershell/startup-virtual-desktop/Startup-VirtualDesktop.ps1`
- Test: `powershell/startup-virtual-desktop/tests/StartupVirtualDesktop.Entry.Tests.ps1`

**Interfaces:**
- Consumes: Task 1 の日本語メッセージ・コメント期待値
- Produces: 同じ終了コードとログ構造を維持する日本語のエントリポイント

- [ ] **Step 1: スクリプトが直接生成する文言を日本語化する**

以下の意味になるように、ログ、警告、出力、例外の文字列リテラルを置換する。

```text
別の起動処理が実行中です。
起動環境を検出しました。

VirtualDesktop モジュールがインストールされていません。
VirtualDesktop <version> がインストールされています。1.5.11 以降を推奨します。
設定の検証に成功しました。
VirtualDesktop モジュール 1.5.9 以降が必要です。Install-Module VirtualDesktop -Scope CurrentUser を実行してください。
Windows Explorer が 30 秒以内に起動しませんでした。
デスクトップ配置処理が完了しました。
デスクトップ配置が完了しました: 全 <total> 件、失敗 <failed> 件。ログ: <path>
```

- [ ] **Step 2: 処理単位の日本語コメントを追加する**

```powershell
# 1 行 1 JSON 形式で実行ログを記録する
# 二重起動を防止する
# 必要なモジュールと設定ファイルを読み込む
# 実行環境と VirtualDesktop モジュールのバージョンを確認する
```
